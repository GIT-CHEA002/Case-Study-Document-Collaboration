## Class Diagram
---
The Class Diagram represents the main entities and relationships within the Healthcare Patient Management System.

Important classes include StaffMember, SmartCard, Clinic, Patient, Appointment, Consultation, Treatment, Prescription, DosageChecker, AuditLog, DrugCostReport, and OfflineRecord.

The relationships between these classes describe how patient appointments, consultations, treatments, prescriptions, audit records, and offline records are associated. The diagram also shows that prescriptions are checked by the DosageChecker and that prescription information contributes to drug-cost reporting.

This diagram provides the structural model of the system and supports the implementation of the functional requirements.

Related Requirements: SR-F02, SR-F03, SR-F04, SR-F05, SR-F06, SR-F07.
